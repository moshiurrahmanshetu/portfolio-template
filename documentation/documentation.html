1. Introduction & Overview

Reeni is a commercial-quality, modern, fully semantic personal portfolio, resume, and creative studio landing HTML5 template. Crafted explicitly for elite markets such as Envato ThemeForest, Reeni utilizes modular structural layouts, smooth CSS3 micro-interactions, responsive grids, and vanilla JavaScript physics to establish an uncompromising premium impression.

This technical guide serves as an operational roadmap for customization, styles overriding, JavaScript variables optimization, and deployment best practices.

2. Folder Structure

The template codebase follows a clean, standardized architectural structure: 

├── assets/
│   ├── css/
│   │   └── style.css            # Custom Core Design System & Theme Styles
│   ├── js/
│   │   ├── main.js              # Vanilla JS Physics & Core UI Functions
│   │   ├── blog-details.js      # Blog article detail controller
│   │   ├── coming-soon.js       # Countdown clock & launch newsletter script
│   │   ├── contact.js           # Secure inquiry form validator
│   │   ├── faq.js               # Accordion expand/collapse engine
│   │   ├── pricing.js           # Monthly/yearly pricing toggle module
│   │   └── service-details.js   # Service interactive gallery controller
│   ├── fonts/                   # Local Typography Cache
│   └── images/                  # Media mockups, background grids, logo elements
├── documentation/
│   └── documentation.html       # This beautiful developer guide page
├── index.html                   # Homepage foundation
├── [other pages]...             # HTML modules for services, portfolios, resume, contact
└── README.md                    # Technical readme overview

3. HTML Best Practices

Reeni's HTML pages are structured with full W3C validity and semantic layout tags. When modifying the HTML structures, maintain these core patterns:

  • Cinematic Preloader: Every page must contain the #preloader element immediately inside the opening <body> tag to ensure smooth asset loading animations.
  • Cursor Dots: To support the custom magnetic mouse effect on large viewports, keep #cursor-dot and #cursor-outline elements active.
  • Breadcrumbs: Support legal navigation using .breadcrumb-reeni nested lists.

4. CSS Design System Variables

Reeni utilizes modern CSS custom variables inside /assets/css/style.css. To modify accents, borders, or layout margins across the entire template instantly, override these variables: 

:root {
  /* Design system custom properties */
  --accent: #d4af37;             /* Luxury Gold accent */
  --accent-rgb: 212, 175, 55;
  --bg-dark: #0f1012;            /* Cinematic twilight background */
  --surface-card: #18191c;       /* Glassmorphic overlay cards */
  --font-sans: "Inter", sans-serif;
  --font-display: "Space Grotesk", sans-serif;
  --radius-lg: 16px;             /* Corner curve smoothing */
}

5. JavaScript Physics & Micro-Interactions

Our core script assets/js/main.js manages interactive physics models including magnetic nodes, cursor acceleration (Lerp), and circular progress bars completely using pure vanilla JavaScript.

To activate the magnetic attraction physics on any custom button, wrapper, or image container, wrap the target element inside a container with the class .magnetic-wrap: 

<div class="magnetic-wrap">
  <a href="#" class="btn-reeni btn-reeni-primary">Interactive Node</a>
</div>

6. Persistent Dark/Light Theme Engine

The template handles themes elegantly via data-theme attributes on the <html> tag. Persistent preferences are cached inside client-side localStorage.

To change the template's default load style from Dark to Light, edit the opening HTML tag: 

<!-- Change data-theme value to "light" for light-mode fallback -->
<html lang="en" data-theme="light">

7. SEO & Open Graph Meta Customization

Every page is ready for advanced search engine visibility and social media preview embedding. Replace the template placeholders with authentic meta descriptors in your HTML page head: 

<!-- SEO Meta -->
<meta name="description" content="Your custom meta details here" />
<meta name="keywords" content="portfolio, agency, creative, custom resume" />

<!-- Open Graph / Facebook -->
<meta property="og:type" content="website" />
<meta property="og:title" content="Reeni - Personal Portfolio" />
<meta property="og:description" content="Commercial ThemeForest Portfolio" />
<meta property="og:image" content="assets/images/og-preview.png" />

<!-- Twitter Card -->
<meta name="twitter:card" content="summary_large_image" />
<meta name="twitter:title" content="Reeni - Portfolio" />

8. Inquiry & Newsletter Forms Verification

Form verification occurs serverless inside assets/js/contact.js and assets/js/coming-soon.js. They perform complete client-side checks and structure feedback alerts with elegant glassmorphic alert cards.

To wire these forms to an active email distribution gateway, replace the submit trigger inside the script files or use third-party serverless form services like Formspree, Web3Forms, or custom PHP routing.

9. Browser Support & Valid Codebase

Reeni has been meticulously validated using direct HTML5 checkers, local CSS structure audits, and cross-browser emulators. The template supports 60FPS animations on the following modern web browser platforms:

  • Google Chrome: Version 100+
  • Apple Safari: Version 15+
  • Mozilla Firefox: Version 98+
  • Microsoft Edge & Opera: Latest desktop & mobile builds
